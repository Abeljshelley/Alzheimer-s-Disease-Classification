# Alzheimer’s Disease Classification using Machine Learning

This project is a machine learning-based web application developed for Alzheimer’s disease prediction and analysis.

## Technologies Used

* Python
* Flask
* Scikit-learn
* XGBoost
* HTML/CSS

## Files Included

* `app.py` — Flask backend application
* `index.html` — Frontend webpage

## Note

Datasets, Jupyter notebooks and trained model binaries are excluded from this repository for privacy, security, and repository optimization purposes.
